## 🚀 快速開始

### 1. 克隆專案
```bash
git clone https://github.com/username/cloudy_homework.git
cd cloudy_homework
```

### 2. 選擇專案

```bash
# Template 專案 - 學習模板架構
cd projects/spring-mvc-template
mvn spring-boot:run

# Example 專案 - 查看業務實現
cd projects/spring-mvc-example  
mvn spring-boot:run
```

### 3. 訪問服務

訪問 http://localhost:8080/api/swagger-ui.html 查看 API 文檔
