## 🛠️ 快速開始

### 1. 環境準備
```bash
# 確保環境需求
java --version    # Java 21+
mvn --version     # Maven 3.6+
```

### 2. 克隆專案
```bash
git clone https://github.com/username/cloudy_homework.git
cd cloudy_homework
```

### 3. 選擇學習方向
```bash
# 模板學習
cd projects/spring-mvc-template && mvn spring-boot:run

# 範例學習  
cd projects/spring-mvc-example && mvn spring-boot:run
```

### 4. 訪問應用
- **API 文檔**: http://localhost:8080/api/swagger-ui.html
- **健康檢查**: http://localhost:8080/api/actuator/health
- **H2 控制台**: http://localhost:8080/api/h2-console

## 💡 學習建議

### ✅ **最佳實踐**
1. **動手實踐** - 每個教學都包含可執行的程式碼
2. **理解原理** - 不只是複製貼上，要理解設計理念  
3. **循序漸進** - 按照建議的學習路徑進行
