## 🏗️ 範例架構特點

### 1. 分層架構
```
Controller Layer    → 處理 HTTP 請求，資料驗證
    ↓
Service Layer      → 業務邏輯，事務管理  
    ↓
Repository Layer   → 資料存取，JPA 查詢
    ↓
Database Layer     → H2/MySQL 資料庫
```

### 2. 設計模式應用
- **依賴注入 (DI)**: Spring IoC 容器管理
- **策略模式**: 不同搜索和過濾策略  
- **建造者模式**: RestResponse 靜態工廠方法
- **模板方法**: BaseEntity 通用欄位
- **代理模式**: AOP 切面實現

### 3. 企業級特性
- **統一異常處理**: @RestControllerAdvice 全局處理
- **AOP 橫切關注點**: 日誌、審計、性能監控
- **快取抽象**: @Cacheable, @CacheEvict 註解
- **資料驗證**: JSR-303 Bean Validation
- **API 文檔**: OpenAPI 3 自動生成

## 📊 功能展示

### 1. RESTful API 設計
```http
GET    /api/users              # 查詢用戶列表 (分頁)
POST   /api/users              # 創建用戶
GET    /api/users/{id}         # 根據 ID 查詢用戶
PUT    /api/users/{id}         # 更新用戶
DELETE /api/users/{id}         # 刪除用戶
GET    /api/users/search       # 搜索用戶
```

### 2. 統一回應格式
```json
{
  "success": true,
  "message": "操作成功",
  "data": { /* 實際資料 */ },
  "timestamp": "2024-01-01T10:00:00"
}
```

### 3. 資料驗證
```java
@NotBlank(message = "Username is required")
@Size(min = 3, max = 50)
private String username;

@Email(message = "Please provide a valid email address")
private String email;
```

### 4. 快取支持
```java
@Cacheable(value = "users", key = "#id")
public UserDto getUserById(Long id) { ... }

@CacheEvict(value = "users", allEntries = true)
public UserDto createUser(CreateUserRequest request) { ... }
```

### 單元測試
```java
@ExtendWith(MockitoExtension.class)
class UserServiceTest {
    
    @Mock
    private UserRepository userRepository;
    
    @InjectMocks
    private UserService userService;
    
    @Test
    void shouldCreateUser() {
        // Given
        CreateUserRequest request = CreateUserRequest.builder()
                .username("testuser")
                .email("test@example.com")
                .build();
        
        // When & Then
        assertThat(userService.createUser(request))
                .isNotNull()
                .hasFieldOrPropertyWithValue("username", "testuser");
    }
}
```

## 🚀 快速體驗

### 1. 啟動專案
```bash
cd projects/spring-mvc-example
mvn spring-boot:run
```

### 2. 訪問服務
- **API 文檔**: http://localhost:8080/api/swagger-ui.html
- **健康檢查**: http://localhost:8080/api/actuator/health
- **H2 控制台**: http://localhost:8080/api/h2-console

### 3. API 測試
```bash
# 創建用戶
curl -X POST http://localhost:8080/api/users \
  -H "Content-Type: application/json" \
  -d '{
    "username": "demo_user",
    "email": "demo@example.com",
    "firstName": "Demo",
    "lastName": "User"
  }'

# 查詢用戶
curl http://localhost:8080/api/users/1
```
