# 📚 技術文檔

這個目錄包含了完整的技術文檔，涵蓋架構設計、開發指南等內容。

## 🏛️ architecture/ - 架構設計文檔

深度技術文檔，涵蓋系統設計的各個層面：

### 📄 ARCHITECTURE_DESIGN.md
- **內容**: 微服務架構與現代設計理念
- **適合**: 架構師、技術負責人
- **重點**: 整體系統架構、設計模式、非功能性需求

### 📄 TECH_STACK.md  
- **內容**: 現代 Java 技術棧詳解
- **適合**: 開發人員、技術選型
- **重點**: 技術選擇理由、版本兼容性、升級路徑

### 📄 MODULE_STRUCTURE.md
- **內容**: 清晰的服務邊界設計
- **適合**: 開發人員、架構師
- **重點**: 模組劃分、依賴關係、通信方式

### 📄 DEVELOPMENT_ENVIRONMENT.md
- **內容**: 完整的開發工具鏈
- **適合**: 開發人員、DevOps
- **重點**: 環境搭建、工具配置、CI/CD

## 📖 guides/ - 開發指南

實用的開發指南和最佳實踐：

### 📄 PROJECT_SUMMARY.md
- **內容**: 重構分析與架構對比
- **適合**: 所有角色
- **重點**: 問題分析、解決方案、效果對比

### 📄 SPRING_MVC_PROJECT_SUMMARY.md  
- **內容**: Spring MVC 模板使用與最佳實踐
- **適合**: 開發人員
- **重點**: 模板使用、範例說明、擴展指導

## 📋 閱讀建議

### 🎯 對於新手
1. 先讀 `guides/SPRING_MVC_PROJECT_SUMMARY.md` 了解專案概況
2. 參考 `architecture/TECH_STACK.md` 學習技術選型
3. 實際運行專案體驗效果

### 🏢 對於架構師
1. 重點閱讀 `architecture/ARCHITECTURE_DESIGN.md`
2. 分析 `architecture/MODULE_STRUCTURE.md` 的設計理念  
3. 參考 `guides/PROJECT_SUMMARY.md` 的對比分析

### 👨‍💻 對於開發者
1. 從 `architecture/DEVELOPMENT_ENVIRONMENT.md` 開始搭建環境
2. 學習 `architecture/TECH_STACK.md` 掌握技術細節
3. 實踐 `guides/` 中的最佳實踐建議

## 🔄 文檔維護

這些文檔會隨著專案演進持續更新，確保內容的時效性和準確性。
