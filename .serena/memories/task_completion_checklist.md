# 任務完成檢查清單

## 開發任務完成後必須執行的檢查

### 1. 編譯與建構
```bash
mvn clean compile    # 確保代碼能正常編譯
mvn clean package    # 確保能正常打包
```

### 2. 測試執行
```bash
mvn test            # 執行所有測試，確保通過
mvn verify          # 執行完整驗證流程
```

### 3. 代碼品質檢查
- SpotBugs 靜態分析檢查
- JaCoCo 測試覆蓋率報告
- 檢查是否符合 Spring 代碼標準

### 4. 功能驗證
```bash
mvn spring-boot:run  # 啟動應用程式
```
- 驗證新功能是否正常運作
- 檢查 API 端點是否可存取
- 確認日誌輸出正常

### 5. 文檔更新
- 更新相關的 Javadoc 註解
- 如有 API 變更，確認 OpenAPI 文檔正確
- 必要時更新 README 或相關文檔

### 6. Git 提交前檢查
```bash
git status          # 確認變更檔案
git diff            # 檢視變更內容
```
- 確保沒有不必要的檔案被提交
- 提交訊息要清楚描述變更內容

### 7. 配置檢查
- 確認 `application.yml` 配置正確
- 檢查多環境配置 (dev, test, prod) 是否一致
- 驗證安全配置沒有洩漏敏感資訊

## 重要提醒
- **絕對不能提交** 包含密碼、API 金鑰等敏感資訊的代碼
- 確保新加的依賴套件版本與現有技術棧相容
- 遵循既有的分層架構模式
- 保持代碼風格一致性
